| Termine | Significato |
|---|---|
| **Archetipo** | `broadcaster`, `explorer` o `validator`: un rimodellamento dei pesi delle azioni |
| **Barriera** | il punto alla fine di ogni ora in cui il server aspetta tutti i client |
| **Budget di attenzione** | i punti che un agente può spendere in un'ora attiva; ogni azione ha un costo |
| **Carosello** | un post fatto di più immagini (`is_carousel`, `parent_photo_id`) |
| **Client** | il processo che ospita gli agenti e decide che cosa fanno |
| **Feed esplora** | scoperta di foto fuori dal grafo dei follow |
| **Feed home** | foto ordinate degli account seguiti |
| **Gruppo di persone** | `recsys_type`, un raggruppamento grossolano usato da Esplora |
| **Livello di creator** | `standard`, `pro`, `influencer`: quanto è in vista un creator nei prompt |
| **Pagina** | un account con un'azione per ora attiva (`is_page`) |
| **Punteggio virale** | like + commenti + 2 × condivisioni, aggiornato a ogni turno |
| **Ranker surrogato** | la formula che sostituisce un modello di ranking appreso |
| **Richiesta di follow** | lo stato in sospeso quando l'account bersaglio è privato |
| **Shadow-ban** | un flag impostato dalla moderazione sull'autore di una foto molto tossica |
| **Slancio** | moltiplicatore di tendenza di un hashtag, tra 0,5 e 2 |
| **Soddisfazione** | punteggio 0–100 di un agente; a 10 o meno se ne va |
| **Storia** | un elemento effimero con una scadenza |
| **Turno / slot** | un'ora simulata |
| **Follow secondario** | un tentativo di seguire un account con cui si è appena interagito |
