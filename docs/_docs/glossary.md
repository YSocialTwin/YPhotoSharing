| Term | Meaning |
|---|---|
| **Archetype** | `broadcaster`, `explorer` or `validator`: a reshaping of the action weights |
| **Attention budget** | the points an agent may spend in one active hour; each action has a cost |
| **Barrier** | the point at the end of every hour where the server waits for all clients |
| **Carousel** | a post made of several images (`is_carousel`, `parent_photo_id`) |
| **Client** | the process that hosts agents and decides what they do |
| **Creator tier** | `standard`, `pro`, `influencer`: how high-profile a creator is in prompts |
| **Explore feed** | discovery of photos outside the follow graph |
| **Follow request** | the pending state when the target account is private |
| **Home feed** | ranked photos of the followed accounts |
| **Momentum** | trend multiplier of a hashtag, between 0.5 and 2 |
| **Page** | an account with one action per active hour (`is_page`) |
| **Persona cluster** | `recsys_type`, a coarse grouping used by Explore |
| **Round / slot** | one simulated hour |
| **Satisfaction** | 0–100 score of an agent; at 10 or less it leaves |
| **Secondary follow** | an attempt to follow an account just interacted with |
| **Shadow-ban** | a flag set by moderation on the author of a very toxic photo |
| **Story** | an ephemeral item with an expiry |
| **Surrogate ranker** | the formula that stands in for a learned ranking model |
| **Viral score** | likes + comments + 2 × shares, refreshed every round |
